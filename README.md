# SmartCalculator

A responsive, static, browser-based calculator app.

## Included
- Profit/Loss
- Percentage
- Discount + Tax
- Break-even
- Simple Interest
- Compound Interest
- EMI/Loan
- Area/Perimeter
- Volume
- Construction Cost
- Temperature
- Dark mode
- English / Urdu / Spanish UI
- Local calculation history
- Copy result
- Search
- PWA service worker
- SEO basics

## Publish
Upload all files while preserving the folder structure to a static host such as GitHub Pages, Netlify, or Cloudflare Pages.

## Before production
1. Replace `https://smartcalculator.online/` in `index.html`, `robots.txt`, and `sitemap.xml` with your actual live URL if different.
2. Add a real privacy policy before analytics/advertising.
3. Test all calculations and mobile layouts.
4. For live currency rates, connect a reliable exchange-rate API; do not hard-code rates for production.
